# American Sign Language Dataset

Link dataset in Kaggle: [ASL Dataset](https://www.kaggle.com/datasets/ayuraj/asl-dataset)

## About dataset
- Author: Ayush Thakur
- Numbers of class: 36 classes (10 classes from `0` to `9` and 26 classes from `a` to `z`)
- Number of images: 2512 images (70 images for each class)
- Color image: 3 channels
